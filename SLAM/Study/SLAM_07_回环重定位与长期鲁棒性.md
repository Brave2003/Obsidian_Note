## 核心概念详解

### 1. 词袋模型 (Bag of Words)

**基本思想**：将图像描述为"视觉单词"的直方图，忽略单词的空间位置。

**构建流程**：
1. 从大量图像提取ORB特征描述子
2. 用K-means将描述子聚类成K个"视觉单词"
3. 构建词汇树(Vocabulary Tree)：分层聚类，加速查找
4. 每张图像用出现哪些单词及权重来表示

**相似度计算**：
$$\text{score}(v_1, v_2) = 1 - \frac{1}{2}\left|\frac{v_1}{|v_1|} - \frac{v_2}{|v_2|}\right|$$

**回环检测**：查询与当前帧最相似的3个历史帧 → 如果连续多帧都匹配到同一段历史 → 回环候选。

### 2. 几何验证

**仅靠词袋匹配不够**：外观可能相似但确实不同位置（perceptual aliasing）。

**验证步骤**（ORB-SLAM3方式）：
1. 通过词袋匹配找到候选帧
2. 计算当前帧与候选帧之间的特征匹配
3. 用RANSAC + PnP或对极几何验证
4. 验证通过的内点数足够多 → 确认回环

### 3. 位姿图优化

**为什么不用全量BA？** 回环会同时调整大量位姿和地图点，全量BA太慢。

**位姿图**：
- 节点 = 关键帧的位姿
- 边 = 相对位姿约束
  - 顺序边：VIO/Odometry输出的相邻帧相对位姿
  - 回环边：回环检测得到的非相邻帧相对位姿

**优化问题**：
$$\min_{T_i} \sum_{(i,j)\in E} \|T_i \ominus T_j \ominus \Delta T_{ij}\|^2_{\Sigma_{ij}}$$

### 4. Sim(3) 与尺度修正

单目VIO的尺度会随时间漂移。回环时不仅要修正位姿，还要修正尺度。

**Sim(3)** = SE(3) + 尺度因子：
$$S = \begin{bmatrix} sR & t \\ 0 & 1 \end{bmatrix}$$

回环时：
1. 先用相似变换 Sim(3) 配准回环
2. 得到尺度校正量
3. 将尺度变化传播到整个轨迹

### 5. 全局重定位

当跟踪完全丢失（遮挡、快速旋转等）：

**ORB-SLAM3的重定位过程**：
1. 提取当前帧的ORB特征和词袋向量
2. 在数据库中搜索相似关键帧
3. 对每个候选帧执行 PnP + RANSAC
4. 如果内点足够多，重定位成功，继续跟踪

### 6. 地图合并

**ORB-SLAM3 的多地图系统 (Atlas)**：
- 当重定位失败时，创建新的子地图(Atlas)
- 系统可以在不同地图间切换
- 如果回环发现两段地图重合 → 自动合并

**地图合并的步骤**：
1. 检测地图A的某帧与地图B的某帧构成回环
2. 计算两地图之间的变换
3. 将两个地图的坐标系对齐
4. 合并全局BA

### 7. 长期鲁棒性策略

| 问题 | 检测方法 | 处理策略 |
|------|----------|----------|
| 跟踪丢失 | 内点率低、重投影误差大 | 重定位、创建子地图 |
| 动态物体 | 语义分割或运动一致性异常 | RANSAC剔除、降权 |
| 光照突变 | 特征数量骤降 | 切换曝光参数、依赖IMU |
| 传感器故障 | 时间戳异常、数据缺失 | 降级运行、报警 |
| 尺度漂移 | 回环时的Sim(3)检测 | 回环修正、引入绝对测量 |
| 地图膨胀 | 关键帧/地图点数量增长 | 剔除冗余关键帧和路标点 |

### 8. 故障分析

**如何系统性地找失败场景？**
1. **数据集全覆盖**：跑EuRoC所有序列，找ATE/RPE异常段
2. **场景分类**：
   - 快速旋转：检查陀螺仪饱和
   - 暗光场景：检查特征数量
   - 低纹理场景：检查跟踪质量
   - 动态场景：检查外点率
3. **录制rosbag回放**：在失败位置加断点调试
4. **建立回归测试**：每次修改后跑完整数据集
