## 一、为什么这样规划？

### 你的真实优势
- **大华实习**：环视相机标定、量产经验，这是大多数应届生没有的
- **Fast 4DGS-SLAM**：动态场景建模，连接了SLAM和三维视觉
- **稀疏视角3DGS平台**：自动化管线 + 多算法统一接口，工程能力强

### 你需要补齐的
- **传统SLAM系统认知**：你做过深度学习SLAM，但传统滤波/优化路线需要系统补齐
- **C++ 工程能力**：SLAM岗位核心壁垒
- **BEV前端**：作为增量方向，连接你的SLAM背景和自动驾驶行业

### 为什么BEV作为项目方向？
1. 自动驾驶是SLAM最大的就业市场
2. BEV前端需要几何能力（你的强项），不是纯DL调参
3. "VIO位姿→BEV对齐"这条链路几乎没有竞品在简历上写
4. 面试官看到这条链路会觉得"这个候选人知道自己要做什么"

## 四、nuScenes数据处理要点

### 数据下载优先级

```
1. nuScenes-mini (4GB)     ← 开发和调试用
2. nuScenes-trainval (350GB) ← 最终实验用
```

### 关键数据结构

```
Scene (一段连续驾驶, ~20s)
  └── Sample (一个时间点, 2Hz)
        ├── sample_data: CAM_FRONT (图像)
        │   ├── calibrated_sensor: 相机内外参
        │   └── ego_pose: 车体全局位姿
        ├── sample_data: CAM_FRONT_LEFT
        ├── ... (共6路相机)
        └── sample_data: LIDAR_TOP

关键理解：
- 每一个sample_data都有自己的时间戳
- 6路相机的曝光时间不完全相同 (但很近)
- LiDAR是360°旋转扫描，时间跨度约50ms
- Ego Pose 是车体后轴中心在地面的位姿
```

### 常见坑

1. **坐标系方向**：nuScenes是 X前-Y左-Z上，和ROS的 X前-Y左-Z上 相同。但 OpenCV是 X右-Y下-Z前，注意区分
2. **Ego Pose频率**：只有 2Hz（每0.5s一个），高动态场景可能不够
3. **相机无畸变**：nuScenes已经做了去畸变，用的是针孔模型
4. **传感器时间差**：LiDAR和相机的触发时间有微小偏移

## 五、SLAM框架阅读的实操建议

### 不要做的事
- 不要从头逐行读代码 (会迷失)
- 不要试图理解每一个变量 (关注主流程)
- 不要在还没跑通Demo时就开始改代码
- 不要同时深入多个框架

### 正确的阅读方法

```
Step 1: 跑通Demo，理解输入输出
Step 2: 画出数据流图 (输入→哪个模块→输出)
Step 3: 找到核心函数，用GDB打断点
Step 4: 跟踪一帧完整的处理
Step 5: 理解状态量和残差的定义
Step 6: 看一处你感兴趣的具体实现
Step 7: 修改 → 观察效果 → 理解原理
```

### 以 VINS-Fusion 为例

```bash
# 1. 跑通
roslaunch vins vins_rviz.launch
rosbag play MH_01_easy.bag

# 2. 找到入口
# estimator_node.cpp: process() 是所有IMU和图像数据的入口

# 3. 用GDB跟踪
gdb --args rosrun vins vins_node /PATH/config.yaml
(gdb) b estimator.cpp:processImage
(gdb) r
# 然后在另一个终端播放rosbag

# 4. 关键观察点
# - estimator.cpp:optimization() - 什么时候触发优化？
# - imu_factor.h:Evaluate() - IMU残差长什么样？
# - feature_manager.cpp - 特征点怎么管理的？

# 5. 修改 → 实验
# 例如：修改estimator.cpp中SOLID_TIME (滑窗时间)的大小
# 观察对ATE和帧率的影响
```

3. 它连接了你的SLAM背景和自动驾驶方向
4. 它是一个有"故事性"的项目 (定位误差→特征错位→检测精度)

面试时你能说：**"我在BEVDet4D的基础上实现了历史BEV的Ego-motion对齐，然后系统分析了定位误差对BEV感知的影响——平移误差超过5cm时，3D检测mAP下降约X%。这个工作让我理解了为什么SLAM/VIO的精度对自动驾驶感知系统至关重要。"**

这就是你和其他BEV方向候选人的最大区别。
