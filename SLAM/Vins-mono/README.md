## 统一记号

- `W`：世界系；`B/I`：IMU（机体系）；`C`：相机系。代码中 `Rs[i], Ps[i], Vs[i]` 表示窗口第 `i` 帧 IMU 的世界系旋转、位置、速度。
- `R` 将机体系向量转到世界系；`TIC/RIC` 是相机相对 IMU 的平移/旋转外参。
- 单目没有天然尺度；初始化后通过 IMU 求尺度、重力和速度。
